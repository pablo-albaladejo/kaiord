# Proposal: FIT import works in the SPA production bundle

## Why

Every FIT import on `https://kaiord.com/app` failed with "Failed to parse FIT
file: FIT parsing errors: TypeError: Cannot read properties of undefined
(reading 'DEVELOPER_DATA_ID')": workouts, health files and the FIT the app
exports itself (audit finding F-21).

The SPA build swapped `@garmin/fitsdk`'s `profile.js` for a trimmed copy
generated by `scripts/generate-fitsdk-minimal.mjs` (Vite plugin
`kaiord-fitsdk-profile-trim`). The generator only emitted
`{version, CommonFields, messages, types}` and never copied `MesgNum`, which
the SDK's decoder reads unconditionally (`Profile.MesgNum.DEVELOPER_DATA_ID`).
Its keep-list had no health messages either.

Nothing could catch it. The plugin only acts in `vite build`: the dev server
pre-bundles the SDK, and every Playwright spec ran against the dev server. The
generator claimed that "CI's e2e-frontend … load the generated file" and that
it was "hooked into the SPA's prebuild step"; neither was true.

## What Changes

- The trim is removed: no Vite plugin, no `src/lib/fitsdk-minimal/`, no
  generator, no `generate:fitsdk-minimal` script. The SPA bundles the SDK as
  published. The lazy `kaiord-fit` chunk grows from 39.7 kB to 72.2 kB gzip;
  the initial JS is unchanged (279.9 kB, budget 286 kB) and the chunk stays
  out of it.
- New `e2e/fit-import-prod-bundle.spec.ts`, tagged `@prod-bundle` and gated by
  `E2E_PROD_BASE=1`, imports real FIT files through the UI of the built
  artifact served like the static host: a workout with a repeat block, the
  app's own FIT export, an HRV file and a weight-scale file (health rows
  asserted in IndexedDB). It requires the `kaiord-fit` chunk to be served
  from `/app/assets/`. The `e2e-prod-base` CI job runs
  `--grep '@spa-route-refresh|@prod-bundle'`.
- `deploy-site.yml` writes `app/version.json` (`{"sha": "<commit>"}`) and
  the merged-artifact check requires it, so a check of the live site can tell
  which build it is looking at.

## Impact

- Specs: `spa-quality-gates` gains "Production-bundle FIT import" and
  "Deployed SPA names its commit".
- Code: `packages/workout-spa-editor` (Vite config, e2e), `ci.yml`,
  `deploy-site.yml`. No published package changes.
