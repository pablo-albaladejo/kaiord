Settings → Privacy can now export all your data: "Export my data" downloads one JSON file with your workouts, wellness, health, nutrition and settings. The file is not encrypted and carries no API key (AI providers keep their configuration only) and no integration sync cursors. Exporting does not change your default profile, so it still is not uploaded to Drive until you claim it.
