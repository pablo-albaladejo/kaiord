One current weight: the Athlete page shows the latest weigh-in as "Current weight", and editing it records today's weigh-in (a same-day re-edit updates it). The profile weight is only used when there is no weigh-in. Expenditure, goal maintenance, the goal's start weight and the extension popup all use this same value, so a weigh-in logged in Wellness now shows up everywhere.
