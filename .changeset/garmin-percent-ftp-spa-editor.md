Exporting to Garmin Connect and "Send to Garmin" now convert percent-of-FTP power targets with the FTP from the athlete profile, and show a message asking to set the FTP instead of sending wrong watts when the profile has none. When the workout's sport has no power zones (generic, swimming, none), the message asks to change the sport to cycling or running instead.
