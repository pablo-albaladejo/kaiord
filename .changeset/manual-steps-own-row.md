Manual steps are saved to their own manual daily row, carrying only the steps, instead of re-stamping an imported daily row (such as a FIT file import) as manual. Every daily-wellness reader reads one reading per day: the first source of the source policy, read whole, with manual steps replacing its steps when manual ranks above it. A day with only manual steps is predicted from BMR instead of counting a measured 0 kcal. A daily row that an earlier save re-stamped as manual keeps its calories.
