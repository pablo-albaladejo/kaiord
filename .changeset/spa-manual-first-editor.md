Manual use is the main path. The first run leads with creating, importing and logging wellness, and the setup checklist completes without integrations. The readiness card offers manual entry, and scheduling by hand counts as a planned-session source. The step editor takes duration as m:ss and pace as min/km (min/100 m in the pool) and has an intensity selector; metadata opens read-only, and the FTP line shows only when a target uses FTP. The threshold dialog opens on the active sport, leads with pace and LTHR in running, shows the method actually applied and says when it saved. Library cards no longer show "0 TSS".
