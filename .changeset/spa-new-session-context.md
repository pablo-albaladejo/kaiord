The "New session" sheet keeps the day it was opened for. Blank keeps the day and the chosen sport. Import file imports onto that day. Template opens the Library in picking mode for that day. Close returns to the day's week instead of reopening the sheet. The schedule dialog proposes a date, explains an empty one and speaks Spanish. "Keep in library" proposes the workout's name.
