Light the live core from distance-based sessions. Steps prescribed by distance ("1.3 km Z2") declared intensity the zone distribution threw away — a whole week of swims or distance runs read as "no zone data" and the brand core stayed ink. They now contribute seconds estimated from the sport's pace threshold (no threshold → no estimate, never an invented number). Also collapses the two `dominantZone` implementations into one: ties resolve downward everywhere (a 50/50 Z2/Z4 session is an endurance session with a hard block, not a threshold session), so the week core, card borders, library and proposal cards can no longer disagree on the same distribution.
