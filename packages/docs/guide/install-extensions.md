# Install the extension for each Platform

The Kaiord App reaches each Platform through a Chrome extension that uses your own sign-in on that Platform. There is one extension per Platform, called Kaiord for that Platform.

_Leer en español: [Instala la extensión de cada plataforma](/es/guide/install-extensions)._

## In the Chrome Web Store

- [Kaiord for Garmin](https://chromewebstore.google.com/detail/kaiord-garmin-bridge/innelncjhkdokailkinkchppgekennoe) is published in the Chrome Web Store.
- Kaiord for Train2Go is published in the Chrome Web Store: search for it there by its name.

## Not in the Chrome Web Store yet

- Kaiord for Tanita and Kaiord for TrainingPeaks are not published in the Chrome Web Store yet.
- Kaiord for WHOOP is not published in the Chrome Web Store, because WHOOP's terms prohibit this kind of access. It is experimental.

## Load an extension that is not published

1. Download the Kaiord source code from [GitHub](https://github.com/pablo-albaladejo/kaiord).
2. In Chrome, open `chrome://extensions` and turn on **Developer mode**.
3. Choose **Load unpacked** and select the folder of the extension: [Kaiord for Tanita](https://github.com/pablo-albaladejo/kaiord/tree/main/packages/tanita-bridge), [Kaiord for TrainingPeaks](https://github.com/pablo-albaladejo/kaiord/tree/main/packages/trainingpeaks-bridge) or [Kaiord for WHOOP](https://github.com/pablo-albaladejo/kaiord/tree/main/packages/whoop-bridge).
