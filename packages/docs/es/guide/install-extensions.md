# Instala la extensión de cada plataforma

La aplicación Kaiord llega a cada plataforma a través de una extensión de Chrome que usa tu propio inicio de sesión en esa plataforma. Hay una extensión por plataforma, llamada «Kaiord for» y el nombre de esa plataforma.

_Read in English: [Install the extension for each Platform](/guide/install-extensions)._

## En Chrome Web Store

- [Kaiord for Garmin](https://chromewebstore.google.com/detail/kaiord-garmin-bridge/innelncjhkdokailkinkchppgekennoe) está publicada en Chrome Web Store.
- Kaiord for Train2Go está publicada en Chrome Web Store: búscala allí por su nombre.

## Aún no están en Chrome Web Store

- Kaiord for Tanita y Kaiord for TrainingPeaks aún no están publicadas en Chrome Web Store.
- Kaiord for WHOOP no está publicada en Chrome Web Store, porque las condiciones de WHOOP prohíben este tipo de acceso. Es experimental.

## Carga una extensión que no está publicada

1. Descarga el código fuente de Kaiord desde [GitHub](https://github.com/pablo-albaladejo/kaiord).
2. En Chrome, abre `chrome://extensions` y activa el **modo de desarrollador**.
3. Elige **Cargar descomprimida** y selecciona la carpeta de la extensión: [Kaiord for Tanita](https://github.com/pablo-albaladejo/kaiord/tree/main/packages/tanita-bridge), [Kaiord for TrainingPeaks](https://github.com/pablo-albaladejo/kaiord/tree/main/packages/trainingpeaks-bridge) o [Kaiord for WHOOP](https://github.com/pablo-albaladejo/kaiord/tree/main/packages/whoop-bridge).
